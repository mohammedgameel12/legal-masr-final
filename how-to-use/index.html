01

التثبيت والتشغيل

احصل على حزمة الإصدار 0.1.0 المناسبة لنظام تشغيلك (x64). احتفظ بنسخة منفصلة من أبحاثك المهمة قبل التجربة. لا يوجد تحديث تلقائي في هذا الإصدار.

ويندوز

  1. النسخة المثبّتة: شغّل Research-Notebook-0.1.0-Setup-x64.exe. وهو مثبّت بنقرة واحدة لكل مستخدم.
  2. النسخة المحمولة: شغّل Research-Notebook-0.1.0-Portable-x64.exe. كلمة Portable تصف طريقة تشغيل الملف التنفيذي؛ ولا تُخزَّن مكتبتك بجواره.
  3. الحزم غير موقّعة. إن ظهرت رسالة ثقة في ويندوز فتأكد أولًا أنك حصلت على الحزمة المقصودة.

لينكس

  1. AppImage: اجعل الملف قابلًا للتنفيذ (chmod +x Research-Notebook-0.1.0-linux-x64.AppImage) ثم افتحه.
  2. DEB: sudo apt install ./Research-Notebook-0.1.0-linux-x64.deb
  3. RPM (فيدورا): sudo dnf install ./Research-Notebook-0.1.0-linux-x64.rpm
  4. افتح Research Notebook من قائمة التطبيقات بعد تثبيت DEB أو RPM.

Expected: تُفتح مساحة عمل فارغة أو مكتبتك المحلية الحالية. إن فشل التشغيل فسجّل نص الرسالة بدقة واسم الحزمة. لا تُعد التثبيت مرارًا فوق نسختك الوحيدة من المكتبة.

02

كيف تُخزَّن بياناتك

الدفتر يحتوي مشروعًا بحثيًا. الصفحة تجمع موضوعًا. الملاحظة مستند صغير داخل صفحة. الكتلة جزء واحد من الملاحظة: دليل أو تفسير أو سؤال أو وسائط.

  • يُحفظ كل شيء في قاعدة بيانات SQLite محلية مع مجلدات ملفات مُدارة.
  • الموقع الحقيقي تجده في Application menu ← settings ← Library & Storage ← Active library.
  • الموقع الافتراضي: %APPDATA%\research-notebook في ويندوز، و~/.config/research-notebook في لينكس.
  • لا مزامنة سحابية ولا تسجيل دخول. أما تفريغ OpenRouter فإجراء شبكي منفصل واختياري.
  • تُحفظ النصوص والعناوين عند مغادرة الحقل. انقر خارجه قبل تغيير الصفحة أو إغلاق التطبيق.
  • أبقِ قاعدة البيانات والملفات معًا عند استعادة المكتبة.
03

إنشاء الدفاتر والصفحات والملاحظات

  1. اختر Create notebook (في مكتبة فارغة) أو New notebook أسفل الشريط الجانبي. ينشئ التطبيق Untitled notebook وأول صفحة Untitled.
  2. انقر عنوان الدفتر في الشريط الجانبي واكتب اسمًا، ثم انقر خارج الحقل للحفظ.
  3. انقر Page title أعلى مساحة العمل واكتب اسمًا، ثم انقر خارجه. يتحدّث اسم الصفحة في الشريط الجانبي.
  4. اكتب اسمًا في New page واضغط Enter، أو استخدم أيقونة Create page الصغيرة.
  5. اختر Add note (أو Create first note إن كانت الصفحة فارغة). كرر Add note لإضافة ملاحظات أخرى.

Expected: تظهر في كل ملاحظة أزرار Add block وRecord audio وزر قائمة الأوامر. لا يوجد في هذا الإصدار عنوان ظاهر للملاحظة ولا أمر لإعادة تسميتها أو حذفها.

اختيار الملاحظة المستقبِلة وتحميل الصفحات الطويلة

  1. انقر داخل كتلة نصية أو ركّز على عنصر داخل الملاحظة المطلوبة. يظهر حول مستندها إطار تركيز؛ والنقر على الخلفية الفارغة ليس موثوقًا.
  2. ركّز على الملاحظة من جديد قبل كل اقتطاع من PDF أو إرفاق. إعادة تحميل مساحة العمل تمسح اختيار الملاحظة النشطة، وعندها يستخدم Research capture أول ملاحظة.
  3. في الصفحات التي تزيد على 50 ملاحظة، مرّر إلى Load more notes. كل نقرة تضيف الدفعة التالية.
04

كتابة الكتل الدلالية وحفظها

اختر Write للمحرر بعرض كامل. اختر Add block لكتلة نص عادية، أو افتح قائمة أوامر الكتل (زر Type / for commands) لنوع آخر. اكتب ثم انقر خارج الحقل ليُحفظ. لا يوجد زر حفظ.

  • تستخدم الأنواع السبعة كلها المحرر النصي البسيط نفسه. هي تصنّف الغرض ولا تقيّم المحتوى ولا تجيب عنه.
  • كتلة source text أو quote المُدخلة يدويًا لا تكتسب مصدر PDF. استخدم الاقتطاع من PDF للحصول على رابط المصدر.
  • كتابة / داخل كتلة نصية لا تفتح القائمة في هذا الإصدار. انقر زر Type / for commands.
  • الخيار /audio في القائمة يعرض إرشادات فقط. استخدم Record audio للتسجيل.
  • لا يوجد شريط تنسيق نصوص غنية ولا إدراج للأكواد أو الجداول أو الفواصل.
النوعالاستخدام
textملاحظات عامة
source textدليل أو مادة مستخرجة
commentaryتفسيرك الشخصي
explanationتعليل داعم
questionما تريد التحقيق فيه
answerإجابتك
quoteاقتباس أو مقطع لافت

تكرار الكتلة أو تحريكها أو الإجابة عليها أو حذفها

  1. مرّر المؤشر فوق كتلة وانقر زر الثلاث نقاط Actions for … block.
  2. الأمر Duplicate يضيف نسخة في نهاية الملاحظة نفسها. تحقق من موضعها.
  3. Move up / Move down ينقل الكتلة موضعًا واحدًا، ويُعطَّل الأمر عند البداية أو النهاية.
  4. في كتلة سؤال، يضيف Add answer إجابة فارغة مرتبطة بالعلاقة responds to.
  5. Move to trash يزيل الكتلة بشكل قابل للاسترجاع (انظر قسم سلة المحذوفات).

إعادة الترتيب بالفأرة أو لوحة المفاتيح

  1. اسحب المقبض المنقّط وأفلته على كتلة أخرى في الملاحظة نفسها. النصف العلوي يضعها قبلها، والسفلي بعدها.
  2. أو ركّز على كتلة نصية واضغط Alt + ↑ أو Alt + ↓.
  3. تعمل إعادة الترتيب داخل ملاحظة واحدة فقط، لا بين الملاحظات أو الصفحات.

تحويل الكتل وربط الاستدلال وفحص البيانات الوصفية

  1. افتح Actions ← Inspector. استخدم Convert block للتبديل بين الأنواع النصية السبعة. يُحفظ النص، ولا يمكن تحويل كتل الوسائط.
  2. اختر Relation type: explains أو responds to أو comments on أو summarizes. اتجاه العلاقة من الكتلة المفحوصة إلى الهدف.
  3. اختر الهدف في Block to link ثم Link. الأهداف هي الكتل الأخرى في ملاحظات هذه الصفحة المحمّلة.
  4. استخدم علامة × الصغيرة في صف العلاقة لإزالتها. هذا لا يحذف أيًّا من الكتلتين.
  5. البيانات الوصفية (Metadata) تُعرض كـ JSON للقراءة فقط. وللكتل ذات المصدر يقفز View source provenance إلى المصدر.
  6. اختر Close inspector عند الانتهاء.
05

قراءة PDF واقتطاع الأدلة

يستورد التطبيق نسخة من الملف إلى ملفات الدفتر المُدارة. استخدم ملف PDF خاليًا من المعلومات الخاصة أثناء التجربة.

  1. اختر Research ثم Import (أو Import PDF في عارض فارغ) واختر ملف .pdf محليًا.
  2. اختر أي ملف PDF سبق استيراده في Source document. المصادر تتبع الدفتر كله لا الصفحة فقط.
  3. تنقّل بواسطة Previous page أو Next page أو حقل PDF page. الرقم هو رقم الصفحة الفعلية بدءًا من 1.
  4. استخدم Zoom out / Zoom in. التكبير الأولي يناسب عرض اللوحة؛ ولا يوجد زر للعودة إلى الملاءمة.
  5. يمكنك إدخال رقم صفحة مطبوعة في Printed page. هو مرجع للاستشهاد فقط ولا يُربط تلقائيًا.

Expected: يظهر الـ PDF بجانب ملاحظاتك. ملفات PDF الممسوحة ضوئيًا بلا طبقة نص لا يُستخرج منها نص، ولا يجري هذا الإصدار تعرّفًا ضوئيًا على الحروف (OCR).

اقتطاع النص وإنشاء سؤال وجواب

  1. عدّل Selected PDF text حتى يبقى المقطع المطلوب، أو اكتب نصك أو الصقه. يأتي الحقل معبّأً مسبقًا بنص الصفحة كاملة.
  2. ركّز على عنصر داخل الملاحظة التي ستستقبله، ثم اختر Capture text.
  3. تحقق من كتلة source text الجديدة ورابط Source document · PDF p. …
  4. لإنشاء سؤال وجواب، ضع صيغة السؤال في Selected PDF text واختر Create Q&A. تُنشأ ملاحظة جديدة فيها سؤال بمصدر وإجابة فارغة مرتبطة به.

لا توجد طبقة نص قابلة للتحديد فوق الـ PDF. السحب عبر الصفحة يقتطع صورة مستطيلة لا كلمات. وتغيير الصفحة أو التكبير يعيد تعبئة حقل النص، فأنهِ اقتطاع النص أولًا.

اقتطاع منطقة والعودة إلى مصدرها

  1. ركّز على الملاحظة المستقبِلة. اضغط عند أعلى يسار المنطقة، واسحب لأسفل ولليمين، ثم اترك الزر. استخدم منطقة أكبر من بضع نقاط.
  2. تظهر كتلة لقطة فورًا بلا خطوة تأكيد. إن كانت خاطئة فانقلها إلى Trash وأعد المحاولة.
  3. وأنت في Research اختر Source document · PDF p. …، أو Actions ← View source، أو Inspector ← View source provenance للعودة.
  4. يحفظ اقتطاع المنطقة حدودها وصفحتها، لكن لا يحفظ حقل الصفحة المطبوعة.

قد يفوت القفز إلى المصدر من وضع Write حدث تغيير الصفحة أثناء تحميل العارض. في هذه الحالة انقر الرابط مرة أخرى بعد فتح Research.

إتاحة مساحة للقراءة أو الكتابة

  1. استخدم Collapse notebook sidebar وExpand notebook sidebar في الشريط العلوي.
  2. في Research اسحب الفاصل الرأسي لتغيير عرض لوحتي المصدر والملاحظات.
  3. بدّل بين Write وResearch متى شئت. التبديل يُفرغ العارض، فأعد التحقق من الـ PDF والصفحة ونص الاقتطاع بعده.
06

إرفاق الملفات والصور والصوت

  1. في Research انقر أيقونة الرفع Attach media واختر Attach image أو Attach screenshot أو Attach audio أو Attach file.
  2. اختر ملفًا محليًا. يُنسخ إلى التخزين المُدار ويُضاف إلى الملاحظة النشطة (أو أول ملاحظة). الإلغاء لا يغيّر شيئًا.
  3. في Write يمكن أيضًا إضافة الصور من قائمة الأوامر بالأمر /image.
  4. تحقق من المعاينة أو مشغّل الصوت أو Download attached file في كتل الملفات.

Expected: Attach screenshot يستورد صورة موجودة ولا يلتقط شاشة سطح المكتب. استخدم اقتطاع منطقة PDF للقطة من PDF. وإن بقيت المعاينة على Loading image… فافتح diagnostics ← Scan assets.

بدء التسجيل وإيقافه

  1. في الملاحظة المطلوبة اختر Record audio. امنح إذن الميكروفون إن طُلب. يلزم جهاز إدخال يعمل.
  2. يتحول الزر إلى Stop recording ويظهر مؤشر Recording أحمر مع أشرطة مستوى الصوت.
  3. تُبلَّغ الأجهزة الصامتة أو المفصولة بعبارة Microphone muted أو Microphone disconnected.
  4. اختر Stop recording وانتظر ظهور كتلة الصوت. يُحفظ ملف WAV محليًا.
  5. تحقق من التشغيل قبل التفريغ النصي.

أوقف التسجيل دائمًا قبل تغيير الصفحة أو الوضع أو إغلاق التطبيق. مغادرة ملاحظة قيد التسجيل قد تُسقط التسجيل دون حفظ.

07

إعداد التفريغ النصي واستخدامه

يتطلب التفريغ المحلي نموذج Whisper منزَّلًا وبيئة whisper.cpp المضمّنة معًا. النموذج وحده لا يعوّض غياب بيئة التشغيل.

إدارة نماذج Local Whisper

  1. افتح Application menu ← settings ← Transcription. النماذج: Tiny وBase وSmall وMedium وLarge-v3، وكلها متعددة اللغات.
  2. اختر Download على نموذج. Tiny هو الأصغر وبداية جيدة للتجربة. تُنزَّل النماذج من Hugging Face وتحتاج إنترنت ومساحة قرص؛ ويبقى الصوت محليًا عند التفريغ.
  3. راقب شريط التقدم. Cancel يوقف التنزيل، ويظهر Retry بعد الفشل.
  4. حين يظهر Installed اختر Use as default. النموذج الافتراضي يعرض زر Default معطَّلًا.
  5. لحذف نموذج، عيّن نموذجًا آخر افتراضيًا أولًا، ثم اختر Remove على غير الافتراضي وأكّد.

طلب تفريغ نصي

  1. ارجع بـ Back to workspace. في كتلة صوتية اختر Local Whisper أو OpenRouter في Transcription provider.
  2. اختر Detect language automatically أو اللغة في Language hint. هو تلميح وليس أداة ترجمة.
  3. اختر Transcribe. تظهر العمليات المحلية كمهام في الانتظار أو قيد التشغيل مع نسبة التقدم عند توفرها.
  4. عند الانتهاء يظهر النص المفرَّغ أسفل الأزرار. يبقى الصوت الأصلي مرفقًا.
  5. عند الخطأ اقرأ التنبيه العلوي وخطأ jobs ثم افحص diagnostics. أعد المحاولة بـ Retry للمهام المحلية الفاشلة بعد إصلاح السبب.

إن أبلغ Local Whisper أن الملف المساعد (sidecar) المضمّن مفقود فأنت بحاجة إلى حزمة تتضمن بيئة Whisper. لا يوجد في هذا الإصدار سجلّ للتفريغات ولا محرر للنص المفرَّغ.

بيانات اعتماد OpenRouter والخصوصية

  1. في settings ← Transcription أدخل مفتاحك في API key واختر Save key.
  2. بعد الحفظ تتحول الأدوات إلى Replace API key وRemove key. لا يُعرض المفتاح المحفوظ أبدًا.
  3. في كتلة صوتية اختر OpenRouter واضغط Transcribe فقط عندما تقصد الرفع الخارجي.

يرسل OpenRouter الصوت إلى خدمة خارجية وقد يترتب على الاستخدام رسوم. لا توجد صفحة أسعار داخل التطبيق ولا اختيار لنموذج سحابي ولا زر إلغاء للتفريغ السحابي.

08

البحث فيما هو مفهرس فعلًا

  1. انقر زر البحث في الشريط العلوي أو اضغط Ctrl + K (وCmd + K في ماك).
  2. اكتب كلمة. تتحدث النتائج أثناء الكتابة.
  3. اختر نتيجة لفتح صفحتها. نتيجة عنوان الدفتر تفتح أول صفحة. لا يوجد تمرير مضمون إلى الكتلة المطلوبة.
  4. اضغط Escape للإغلاق دون اختيار.
  • يبحث في عناوين الدفاتر والصفحات والملاحظات النشطة وفي بيانات الكتل المحفوظة.
  • يُقسَّم الاستعلام إلى كلمات تُطابَق بالبادئة، ويجب أن تتطابق كل الكلمات. حتى 100 نتيجة مرتبة.
  • ليس بحثًا بلغة طبيعية ولا بحث عبارة حرفية ولا بحثًا كاملًا في PDF ولا OCR ولا بحثًا في بايتات المرفقات.
  • يصبح نص PDF قابلًا للبحث بعد اقتطاعه ككتلة نصية.
  • حقل Search notes… في الشريط الجانبي عنصر شكلي بلا تصفية. استخدم بحث الشريط العلوي.
  • محتوى سلة المحذوفات مستبعد من الفهرس.
09

التصدير والاستيراد والنسخ الاحتياطي للمكتبة

تصدير دفتر أو صفحة أو الملاحظة النشطة

  1. احفظ تعديلاتك وافتح الصفحة. عند تصدير Active note ركّز على عنصر داخل تلك الملاحظة أولًا.
  2. افتح Page actions ← Export page.
  3. اختر Scope: Notebook أو Current page أو Active note.
  4. اختر زر الصيغة: markdown أو pdf أو lossless json أو ai context.
  5. اختر مجلد الوجهة وانتظر إغلاق النافذة. يُنشأ مجلد فرعي مؤرَّخ جديد.
الصيغةالملفما تتوقعه
markdownnotebook.mdنص مقروء وروابط نسبية إلى الوسائط المنسوخة.
pdfnotebook.pdfنص وصور قابلة للطباعة. تظهر الملفات الصوتية والمرفقات كأوصاف.

ai contextnotebook.mdMarkdown بتسميات مثل [SOURCE] و[COMMENTARY]. لا يُرسَل شيء إلى أي خدمة ذكاء اصطناعي.

يحتوي كل مجلد تصدير أيضًا على manifest.json وassets/. احتفظ بالمجلد كاملًا. تُستبعد العلاقات الخارجة عن النطاق المحدد، فالنطاق الضيق ليس أرشيفًا كاملًا.

استيراد أرشيف lossless

  1. أبقِ ملف .json مع مجلد assets/ المجاور له. استخدم ملف الأرشيف لا manifest.json.
  2. افتح Application menu ← Import backup واختر notebook.lossless.v1.json. تُفحص البنية والبصمات أولًا.
  3. أعد تشغيل التطبيق إن لم يظهر الدفتر الجديد في الشريط الجانبي.
  4. افتح النسخة المستوردة وتحقق من روابط المصادر والمرفقات.

الاستيراد ينشئ نسخة دفتر جديدة بمعرّفات جديدة ولا يستبدل شيئًا. استيراده مرتين ينتج نسختين. لا يمكن استيراد صيغ Markdown وPDF وAI context.

نسخ المكتبة كاملة احتياطيًا

  1. أوقف أي تسجيل. اختر وجهة خارج المكتبة النشطة بمساحة كافية.
  2. اختر Application menu ← Back up library، أو settings ← Maintenance ← Back up library.
  3. افتح jobs وانتظر حتى تظهر مهمة backup بحالة completed.
  4. أبقِ database.sqlite وassets/ وmanifest.json وRECOVERY.md معًا، ويُفضَّل نسخة ثانية على قرص آخر.

إغلاق نافذة اختيار المجلد لا يعني اكتمال النسخ. لا تشمل النسخة الاحتياطية إعدادات المزوّد ولا النماذج المنزَّلة ولا مؤشر موقع المكتبة.

استعادة نسخة احتياطية للمكتبة

  1. لا يوجد زر استعادة، وImport backup ليس مسار استعادة نسخة المكتبة. اطلب مساعدة المشرف إن لم تكن متأكدًا.
  2. سجّل مسار Active library ثم أغلق التطبيق تمامًا.
  3. احفظ المكتبة الحالية كاملة في مجلد استعادة منفصل، بما فيه الملفات المساعدة لقاعدة البيانات.
  4. تحقق من بصمات SHA-256 للملفات في manifest.json باستخدام RECOVERY.md.
  5. ضع database.sqlite وassets/ من النسخة معًا في موقع المكتبة النشطة. تأكد ألا تبقى ملفات database.sqlite-wal وdatabase.sqlite-shm القديمة بجوارها.
  6. إن كانت المكتبة قد نُقلت فاستعد إلى المسار الذي يحدده مؤشرها فعليًا.
  7. أعد تشغيل الإصدار نفسه وتحقق من أعداد الدفاتر والنصوص وروابط المصادر والصوت والملفات.

الإعدادات والتخزين والمهام والتشخيص

المظهر والكثافة

  1. افتح Application menu ← settings ← General.
  2. اختر Appearance: Use system setting أو Light أو Dark.
  3. اختر Layout density: Default أو Compact. تُطبَّق التغييرات فورًا دون إعادة تشغيل.

نقل المكتبة

  1. أنشئ نسخة احتياطية للمكتبة، واحفظ تعديلاتك، وأوقف أي تسجيل أولًا.
  2. افتح settings ← Library & Storage ودوّن مسار Active library والأحجام.
  3. اختر Move library… وحدد مجلدًا أصلًا. ينسخ التطبيق البيانات ويتحقق منها في مجلد جديد.
  4. انتظر Move verified. Restart the application to activate the new library.
  5. أعد التشغيل وتأكد من مسار Active library الجديد ومن محتواك.
  6. عندما ترتاح وتكون قد أخذت نسخة احتياطية اختر Remove original وأكّد. هذا يحذف الأصل المحتفَظ به نهائيًا.

لا يتم التفعيل إلا بعد إعادة التشغيل. تجنّب أي تعديلات جديدة بين النقل المُتحقَّق منه وإعادة التشغيل.

المهام: التقدم والإلغاء وإعادة المحاولة

  1. افتح Application menu ← jobs، أو settings ← Maintenance.
  2. الحالات: queued وrunning وsucceeded وfailed وcancelled.
  3. اختر Cancel لمهمة في الانتظار أو قيد التشغيل. قد ينتظر حتى نقطة فحص.
  4. أصلح سبب فشل المهمة ثم اختر Retry. تُنشأ محاولة جديدة ويبقى الصف القديم.

يستخدم التفريغ المحلي وتنزيل النماذج والنسخ الاحتياطي ونقل المكتبة نظام المهام. إعادة التشغيل أثناء مهمة جارية تعلّمها كمقطوعة.

التشخيص وفحص الملفات

  1. افتح Application menu ← diagnostics. صفّ حسب العملية أو الخطورة أو الفئة.
  2. وسّع خطأً واختر Show full detail لقراءة رسالته وسياقه وتتبّعه.
  3. اختر Export diagnostics وحدد مجلدًا. راجع النص بحثًا عن مسارات محلية قبل مشاركته.
  4. اختر Scan assets (أو settings ← Maintenance ← Scan active notebook assets) لعدّ الملفات المفقودة وغير المشار إليها وغير المتتبَّعة.

الفحص يُبلغ فقط ولا يحذف ولا يصلح أي ملف، وExport diagnostics لا يرسل ملاحظات إلى أحد. لا تحذف الملفات غير المشار إليها بشكل أعمى.

سلة المحذوفات والإجراءات المدمّرة

جرّب بمواد قابلة للتضحية وخذ نسخة احتياطية قبل أي حذف نهائي. السلة محلية وليس فيها حذف تلقائي بمرور الوقت.

  1. كتلة: Actions ← Move to trash، أو Inspector ← Move to trash.
  2. صفحة: Page actions ← Move page to trash. تذهب ملاحظاتها وكتلها معها.
  3. دفتر: أيقونة السلة الصغيرة بجوار عنوانه في الشريط الجانبي. لا يوجد تأكيد لهذه النقلات القابلة للاسترجاع.
  4. افتح Application menu ← trash، وابحث عن العنصر بالعنوان والنوع والتاريخ، ثم اختر Restore. استعادة العنصر الأب تستعيد كل ما حُذف معه.
  5. اختر Delete فقط حين لا تحتاج العنصر بعد الآن.

Delete نهائي وليس له تأكيد ثانٍ في هذا الإصدار. لا يوجد Empty Trash ولا أمر مباشر لحذف ملاحظة.

أول جلسة موجَّهة

استخدم مكتبة قابلة للتضحية وملف PDF غير خاص وصورة صغيرة وميكروفونًا اختياريًا. خصّص نحو 20 إلى 30 دقيقة دون احتساب التنزيلات.

  1. أنشئ Learning research، وغيّر اسم أول صفحة إلى Reading and reasoning، وأضف ملاحظة.
  2. أضف كتلة text (هدف البحث) وcommentary وquestion. غادر كل حقل ليُحفظ.
  3. استخدم Add answer على السؤال وتأكد من العلاقة responds to في Inspector.
  4. كرّر كتلة، وأعد ترتيبها بالقائمة وبـ Alt + ↑/↓، ثم احذفها إلى السلة واستعدها.
  5. أنشئ Practice captures وأضف ملاحظة وافتح Research واستورد ملف PDF.
  6. قصّ النص المستخرج إلى مقطع واختر Capture text. أنشئ ملاحظة Q&A واقتطع منطقة صغيرة.
  7. انقر رابط المصدر وأنت في Research وتأكد من الصفحة الصحيحة. غيّر الفاصل وبدّل الشريط الجانبي.
  8. أرفق صورة وملفًا. سجّل مقطعًا قصيرًا وأوقفه قبل أن تغادر.
  9. افحص إعداد التفريغ. اعتبر غياب بيئة التشغيل أو النموذج حالة «محجوبة» لا نجاحًا.
  10. ابحث عن كلمة محفوظة. صدّر الصفحة بصيغتي Markdown وPDF، والدفتر بصيغة lossless JSON.
  11. استورد أرشيف lossless كنسخة جديدة وأعد التشغيل. أنشئ نسخة احتياطية كاملة وتأكد من اكتمال المهمة.
  12. أعد فتح التطبيق وتحقق من محتواك. صدّر التشخيص إن فشل شيء.
